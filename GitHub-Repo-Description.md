# GitHub Repository Description

Three variants, each within GitHub's 350-character limit for the repository
description field. Character counts are exact, computed with `len()` over the
string as it would be pasted into the field.

Pick by audience: **Variant 1** for a practitioner browsing GitHub search,
**Variant 2** for a university or conference context where authorship and
standards alignment matter, **Variant 3** when the description is displayed
alongside a topic list that already carries the keywords.

---

## Variant 1 — Practitioner — 340/350 characters

```
Runnable companion to a security-first software testing course. Zero runtime dependencies; the full suite passes with no Docker and no network. Property-based and mutation testing, exhaustive authorisation-matrix tests, KEV/EPSS vulnerability triage, SBOM, VEX and provenance verification, plus an auditor that detects assertion-free tests.
```

## Variant 2 — Academic — 327/350 characters

```
Teaching repository by Prof. Etemi Joshua Garba (2026) accompanying a 56-slide course on software testing and evaluation. Every code-bearing slide becomes tested, dependency-free Python, aligned to OWASP Top 10:2025, ASVS 5.0, NIST SP 800-218 and ISO/IEC 25010:2023. MIT licensed; no permission required to teach from or adapt.
```

## Variant 3 — Concise — 301/350 characters

```
Security-first software testing, as runnable code. Property-based and mutation testing, authorisation matrices, risk-based vulnerability triage, SBOM/VEX/provenance checks, and an assertion-free-test detector. No runtime dependencies; offline test suite. MIT, no permission required to adopt or adapt.
```
